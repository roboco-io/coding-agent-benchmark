# 2026-09-21 계측 정정 기록

## 범위와 검증

EXP-001~004의 보관 로그 9개 run만 재집계했다. 원자료는 수정하지 않았다.
`aggregate_tokens.py` v2는 run 디렉터리 내 message.id를 중복 제거한다.
동일 ID의 다른 usage는 임의 선택하지 않고 오류로 중단한다. 누계형 Codex 로그는 지원하지 않으며 오류로 거부한다.
누락은 null(미측정), 명시적 0은 0으로 보존한다. 잘못된 JSON·ID 누락·빈 입력은 오류다.

검증: `python3 -m unittest discover -s scripts -p 'test_*.py'`.
수정 전 중복 재현 테스트에서 입력 20 대신 40이 나왔으며 수정 후 통과했다.
[재집계 JSON](2026-09-21-usage-corrections.json)에 입력·집계기 SHA-256과 명령을 보관한다.
최상위 JSONL만 포함하며 누락된 서브에이전트·외부 요청의 완전성을 보장하지 않는다.
