# EXP-002 결과 보고: 한국어 vs 영어 파이프라인 토큰 비교

- 실험일: 2026-07-21
- 가설: [L-01](../../hypotheses/catalog.md) — 전 파이프라인 영어 진행이 한국어 대비 토큰 대리지표 토큰을 유의미하게 줄인다
- **판정: 보류** — 토큰 대리지표 KO 평균 114,605.5, EN 평균 112,463.5. 평균 차 2,142가 최대 조건 내 범위 23,033보다 작아 사전 규칙 미충족.

## 2026-09-21 계측 정정

동일 run 안의 동일 `message.id`·usage를 한 번만 합산했다. 아래 값은 보관된 최상위 JSONL 파일 범위이며 실제 청구 비용이 아니다. `messages`는 고유 메시지 수, `sessions`는 JSONL 파일 수다. 누락된 외부 호출·서브에이전트 비용의 완전성은 미검증이다.

| run | 이전 대리지표 | 정정 대리지표 |
|---|---:|---:|
| ko-1 | 270,352 | 111,247 |
| ko-2 | 307,930 | 117,964 |
| en-1 | 190,907 | 100,947 |
| en-2 | 329,020 | 123,980 |

이전 값은 중복 usage 행을 합산했다. 기존 보고서의 해당 수치·파생 해석은 이 정정판으로 대체한다. 원자료는 변경하지 않았다.

## 정정 측정 결과

| 지표 | ko-1 | ko-2 | en-1 | en-2 |
|---|---:|---:|---:|---:|
| sessions | 1 | 1 | 1 | 1 |
| messages | 40 | 38 | 41 | 44 |
| usage_rows | 84 | 82 | 70 | 94 |
| duplicates | 44 | 44 | 29 | 50 |
| missing_usage | 0 | 0 | 0 | 0 |
| input_tokens | 75 | 455 | 77 | 81 |
| output_tokens | 29,027 | 31,913 | 25,278 | 31,719 |
| cache_creation_input_tokens | 82,145 | 85,596 | 75,592 | 92,180 |
| cache_read_input_tokens | 2,936,560 | 2,863,848 | 2,724,719 | 3,468,089 |
| token_proxy | 111,247 | 117,964 | 100,947 | 123,980 |

`token_proxy = input_tokens + output_tokens + cache_creation_input_tokens`. 캐시 읽기는 별도 표시하며 무료로 취급하지 않는다. reasoning은 공급자가 output에 포함한 값을 중복 가산하지 않는다.

## 판정·관측·한계

- 기존 완료 관측: 네 run 모두 Hurl 13/13·154/154, 첫 iteration, 약 6–8분. 재실행하지 않았다.
- KO 범위 6,717, EN 범위 23,033. KO−EN 평균 차 2,142는 EN 평균 대비 약 1.90%이나 언어의 인과 효과로 해석하지 않는다.
- 사전 판정 규칙은 평균 차가 조건 내 run 범위를 넘어야 한다는 탐색 기준이다. 통계적 유의성 검정은 아니다.
- 각 조건 n=2·한 과제이며 en-2 최종 보고 언어의 부분 미준수가 있었다. 일반적 언어 효과나 필요한 반복 수를 확정할 수 없다.
- [정적 문서 측정](static-measurement.md)은 별도 관측이며 전체 작업 효율을 직접 예측하지 않는다.
- 기존 29K 평균 차·138K 범위·최소 n≥5 추정·저렴하다는 비용 표현을 철회한다.
