# EXP-004 결과 보고: Ralph loop + 스킬 구조

- 실험일: 2026-07-21
- 가설: [S-03](../../hypotheses/catalog.md) — 단일 세션 ralph에 도메인 계약 스킬을 제공하면 토큰 대리지표이 감소한다
- **판정: 보류** — 스킬 토큰 대리지표 117,352 / 118,311, 기준 KO 평균 대비 +2.81%. 두 스킬 run의 범위는 959이며 효과 없음·두 배 변동 주장을 철회한다.

## 2026-09-21 계측 정정

동일 run 안의 동일 `message.id`·usage를 한 번만 합산했다. 아래 값은 보관된 최상위 JSONL 파일 범위이며 실제 청구 비용이 아니다. `messages`는 고유 메시지 수, `sessions`는 JSONL 파일 수다. 누락된 외부 호출·서브에이전트 비용의 완전성은 미검증이다.

| run | 이전 대리지표 | 정정 대리지표 |
|---|---:|---:|
| ko-1 | 270,352 | 111,247 |
| ko-2 | 307,930 | 117,964 |
| skills-1 | 399,604 | 117,352 |
| skills-2 | 198,819 | 118,311 |

이전 값은 중복 usage 행을 합산했다. 기존 보고서의 해당 수치·파생 해석은 이 정정판으로 대체한다. 원자료는 변경하지 않았다.

`token_proxy = input_tokens + output_tokens + cache_creation_input_tokens`. 캐시 읽기는 별도 표시하며 무료로 취급하지 않는다. reasoning은 공급자가 output에 포함한 값을 중복 가산하지 않는다.

## 판정·관측·한계

- 기존 완료 관측: 기준과 스킬 네 run 모두 Hurl 154/154, 첫 iteration. 이번 작업에서 재실행하지 않았다.
- 기준 평균 114,605.5, 스킬 평균 117,831.5, 차이 +3,226(+2.81%). 기준 범위 6,717, 스킬 범위 959이므로 평균 차가 최대 조건 내 범위를 넘지 못한다.
- n=2·단일 과제에서 감소를 입증하지 못했다. 동등성이나 효과 없음의 증거로 해석하지 않는다.
- 두 run 모두 Skill 호출 없이 여섯 SKILL.md를 읽었다는 기존 관측은 유지한다. 모든 단일 세션에서 점진 공개가 무의미하다는 일반화는 철회한다.
- 기존 스킬을 재사용했으므로 스킬 작성 비용은 제외돼 있다. 전체 생애주기 비용은 미측정이다.
- 200,785토큰·약 두 배 변동과 스킬은 멀티 세션에서만 유효하다는 기존 결론을 철회한다.
