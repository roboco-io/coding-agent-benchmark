## 관찰

1. **무개입 완주 재현성**: 3/3 iter 1 완주로 네이티브 계열(Opus 4.8 6/6, Opus 5 9/9)과 동일한 최상위 완주 프로파일. 상위 티어 모델의 rate limit·서빙 장애 리스크 항목 0건.
2. **프로파일은 Opus 5가 아니라 Opus 4.8 쪽**: output 28.7–35.8K는 Opus 4.8(29.6–37.1K)과 겹치고 Opus 5(41.1–48.4K)와는 겹치지 않는다. 시간은 6.2–7.8분으로 **네이티브 전 조건 중 최속**(4.8 하한 7.8분보다 아래). EXP-010이 "세대 특성"으로 확정한 Opus 5의 산출량 확대 프로파일은 같은 세대의 상위 모델에서 재현되지 않았다 — 산출량 확대는 세대가 아니라 **모델(Opus 5) 고유 프로파일**로 재해석해야 한다. 시점 차(EXP-010과 7주)와 CLI 버전 차가 있으므로 방향성 기록.
3. **Bash 단일 도구 궤적**: 3 run 합계 71회 Bash에 Write 2회뿐, Read/Edit 0회. 파일 작성·확인을 전부 heredoc·cat으로 처리했다 — 이 리포의 실험 조율 세션에서 bypass 모드 시 Bash 우선 지침이 노출되는 것과 같은 환경 규칙(비격리)의 영향일 수 있으며, 모델 고유 성향인지는 격리 조건에서 재확인 필요.
4. **비격리 노출 항목**: 2/3 run이 글로벌 MCP(context7) 문서 조회를 1–3회 사용, 최종 메시지 한국어. 기준선(EXP-009/010/019)도 동일 비격리 조건이었으나 당시 글로벌 설정과 내용이 다를 수 있어 완전 동형은 아님(설계서 리스크 절 명기).
5. **커밋 규율**: 2–4회로 4.8(1–2)과 5(4–8) 사이. run마다 다른 분할(4→3→2)이라 스타일 판단은 유보.
