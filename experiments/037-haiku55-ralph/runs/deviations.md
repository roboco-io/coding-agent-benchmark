# EXP-037 이탈 기록

## D-1. 구독 인증이 아니라 Anthropic API 키로 실행됨 (2026-10-08 실험 종료 후 발견)

- **사실**: 설계(README)는 `claude-native` 하네스를 구독 인증으로 실행한다고 적었다. 그러나 Phase 0 스모크 출력(`phase0.log`)의 인증 출처가 `"apiKeySource":"ANTHROPIC_API_KEY"`였다. 같은 하네스의 EXP-031 스모크는 `"apiKeySource":"none"`(구독)이었다.
- **원인**: 2026-10-08 07:07에 수정된 `~/.zsh_secrets`가 `ANTHROPIC_API_KEY`를 export하고, 실행 셸이 이를 물려받았다. 당시 스킬의 `claude-native` 경로는 `claude-direct` 경로와 달리 이 변수를 지우지 않았다. Claude Code는 API 키가 있으면 구독 로그인보다 API 키를 우선한다.
- **영향**:
  - 완주 판정(3/3): 채점은 하네스의 Hurl 결과만 보므로 인증 방식이 판정 절차를 바꾸지 않는다. 다만 인증·TTL이 모델 행동에 영향을 주지 않았다는 것을 따로 검증하지는 않았다.
  - 3 run은 Anthropic API 요금이 실제로 청구됐다. 보고서의 "구독 OAuth 실행, 실제 청구 미측정" 기술은 틀렸다.
  - 캐시 쓰기가 전부 5분 TTL이 된 원인이다. Claude Code 공식 문서(https://code.claude.com/docs/en/prompt-caching)는 1시간 TTL을 구독의 플랜 포함 사용량에서만 요청하고, API 키 실행은 5분이라고 적는다. 2026-10-08에 같은 Claude Code 2.1.293·같은 모델로 API 키를 제거하고 스모크를 다시 실행하자 `"apiKeySource":"none"`, `ephemeral_1h_input_tokens` 23,666(5분 0)으로 기록됐다.
  - 다른 네이티브 Claude 실험(EXP-023/026/028/031, 구독 인증)과 인증 방식이 다르다. 캐시 TTL이 달라 캐시 쓰기 단가와 캐시 재사용 조건이 달라지므로, 비용 비교에 이 차이가 포함된다.
- **5분 TTL의 영향 점검 (2026-10-08, 세션 jsonl 기준)**:
  - 캐시 만료: 같은 세션 안의 연속 요청 간격은 최대 44초(en-1), 25초(en-2), 36초(en-3)로 5분을 넘은 간격이 없었다. 세션 중간에 15K 토큰 넘게 캐시를 새로 쓴 요청도 없었다. 따라서 이번 run에서는 5분 TTL 때문에 캐시가 만료돼 다시 쓴 사례는 관측되지 않았다.
  - 세션 첫 요청: 모든 세션이 약 10.8–13.2K를 캐시에서 읽고 19–21K를 새로 썼다. 새로 쓴 부분은 run마다 다른 작업 디렉터리·지침이 들어간 부분으로 보여 1시간 TTL이었어도 새로 썼을 가능성이 높지만, 1시간 TTL 조건으로 실행해 비교하지는 않았다.
  - 환산 비용: 같은 토큰을 1시간 TTL 캐시 쓰기 단가로 계산하면 run당 $0.0065–0.0124(8–12%) 높다. 즉 보고한 환산 비용은 구독(1시간 TTL)으로 실행한 다른 네이티브 Claude 조건과 같은 기준이 아니며 그만큼 낮게 잡혀 있다.
  - 세션 시간: API 키 경로와 구독 경로의 응답 지연·레이트 리밋 차이는 측정하지 않았다. 세션 시간 비교에 인증 방식 차이가 섞여 있을 수 있으며, 영향이 없다고 단정하지 않는다.
- **조치**: 스킬 `driver.sh`·`smoke.sh`의 `claude-native` 경로를 `env -u ANTHROPIC_API_KEY -u ANTHROPIC_AUTH_TOKEN -u ANTHROPIC_BASE_URL`로 실행하도록 고치고, smoke가 `"apiKeySource":"none"`이 아니면 FAIL을 내도록 했다. 이 실험의 데이터는 재실행하지 않고 "API 키 인증 조건"으로 정정해 남긴다.
