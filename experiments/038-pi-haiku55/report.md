- 같은 날 두 하네스의 Haiku 5.5는 output·호출 수가 비슷한 범위였다. pi 쪽은 3 run 모두 iteration 1에 끝났고 세션 시간 산포가 작았다(5.4–5.9분). 시작 프롬프트 크기가 pi 쪽이 작아(첫 요청 약 3K vs Claude Code 약 32K) 100K를 넘은 요청이 적었다(3건 vs 13건). n=3이며 우열로 확정하지 않는다.
- pi × Sonnet 5.5(EXP-032) 대비 output·호출 수가 3–4배이고 세션은 약 2배 길었지만, 단가가 1/20이라 환산 비용은 낮다.
- 행동 특징: 3 run 모두 Fastify + Prisma를 선택했다. 포트는 run 1이 `PORT ?? 8000`, run 2가 `PORT ?? 3000`으로 주입값을 따랐고, run 3은 `API_PORT ?? 8000`으로 변수명을 바꿔 무시했다(채점은 LISTEN 포트 자동 탐지라 영향 없음).
